# Insurance Management Platform Frontend

Responsive React starter for the Insurance Management Platform.

## Scope

Version one focuses on Health Insurance.

Other insurance types are shown as coming soon:

- Vehicle Insurance
- Life Insurance
- Travel Insurance
- Property Insurance

## Run Locally

```bash
cd frontend
npm install
npm run dev
```

## API URL

By default, the frontend expects the backend at:

```text
http://127.0.0.1:8000
```

Set a custom backend URL with:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```
